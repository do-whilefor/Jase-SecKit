# Observer validity and differential controls

## Use signals
Use for an existence oracle, lockout transition, timing/size difference, noisy
negative control, or a harness that reports success without retained responses.
This is a method, not current-target evidence or permission to run a script.

## Prerequisites
Identify the exact claim, known-positive membership source, tested operation,
observer, and retained raw responses. A newly generated identifier is only a
candidate negative: wildcard accounts, auto-provisioning, normalization, and
shared counters can invalidate it. Record how absence is established or leave
it unknown. The negative must have a valid format and traverse the same protocol.

## Discriminating test
Retrieve the positive and negative sequences with their order, session,
source, cooldown, counter state, and deployment. Compare the semantic field
predicted by identifier existence; preserve volatile values in raw evidence
while declaring which values the comparison excludes. A body digest identifies
bytes, not meaning. If timing is the proposed signal, use a bounded sampling
plan with order control and an explicit noise question; a single elapsed-time
difference is insufficient. If responses match because every request was
rejected before lookup, restore a valid observer before interpreting equality.

## Valid and invalid observations
Valid: raw completed responses, verified memberships, successful protocol
control, and compatible conditions that distinguish the competing explanation.
Invalid: timeout treated as rejection, expired session, identical error pages,
uncontrolled rate limits, random name assumed absent, or a harness verdict
whose underlying requests and transport status were discarded.

## Support / refute / uncertain
Support only the measured semantic differential when it follows membership
under the stated controls. A valid negative reproducing the claimed positive
signal refutes that signal's proposed specificity under those conditions; it
does not refute every possible oracle. Missing membership, controls, raw data,
or unresolved timing noise means uncertain, even if the script printed a checkmark.

## Stop and reopen
Stop the branch when a shared counter or invalid observer explains the result,
or when the bounded valid comparison answers the question. Preserve the exact
claim and negative result. Reopen only for changed membership, observer,
counter policy, deployment, or a new discriminating signal.
