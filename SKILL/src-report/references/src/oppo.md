# OPPO SRC 内容指南

只在目标为 OPPO 时读取本指南和 `oppo.json`。配置版本 `2026-10-07.1`，**2026-10-07** 通过 Chrome MCP 核对 [官方提交页](https://security.oppo.com/cn/add) 的可见字段、正文模板及控件属性。未填写真实报告、上传、保存或提交；页面标记不等于服务端规则已实测。

## 字段与正文

默认表单有 `title`、`severity`、`type_primary`、`type_secondary`、`details`、`attachments`、`agreement` 七个字段。前五项所属标签有必填星号，两个类型框共用标签；附件和协议未标星，以 `required=null` 表示未确认。另有十个按类型启用的字段定义，总计十七个。

九个一级类型及对应 168 个子类已读取，子类通过 `options_by_parent` 绑定一级；保留页面大小写、CWE 文案与原词，不自行合并近义选项。等级为低危漏洞、中危漏洞、高危漏洞、严重漏洞，不能用其他平台或 CVSS 等级替代。

| 选择条件 | 显示字段与必填状态 |
| --- | --- |
| web漏洞 / 服务器漏洞 | `domain` 域名必填。 |
| 安全情报 / 隐私漏洞 / AI大模型漏洞 | `business_type` 必填，选项 web、app；选择 web 时 `domain` 必填。 |
| 移动应用漏洞，或安全情报 / 隐私漏洞 + app | `business_name` 必填；`package_name` 未标必填。 |
| 开发者APP漏洞 | `developer_package_name` 包名必填。 |
| AI大模型漏洞 + app | `ai_package_name` 包名必填，没有业务名称字段。 |
| 终端安全漏洞 | `terminal_business_type` 必填，APP/FRAMEWORK/NATIVE/TEE/KERNEL/其他；`terminal_product_name` 未标必填。 |
| IoT安全漏洞 | `product_type`（手表/平板/耳机）与 `iot_product_name` 均必填。 |

同名包名、产品名称按条件使用不同键，以保留实际控件与必填差异；不用一条统一规则覆盖所有分支。`all` / `any` 同时检查主类型和业务类型，不能因之前选过 web/app 就启用不属于当前主类的字段。

移动应用、安全情报及隐私 app 分支的业务名称菜单均为相同 52 项。双行 DOM 文本“主题商店\n主题VIP”是单个选项，配置用选中后显示的“主题商店 主题VIP”作为一个值，不拆成两项。包名可输入或选择，不设置封闭枚举；选中该业务时仅观察到 `com.heytap.themestore`、`com.oplus.themestore` 两个关联示例，不能将其当成全部合法包名。

九个一级、情报/隐私/AI 的 web/app、终端六种业务类型和 IoT 三种产品类型已切换。IoT 三种产品均只显示必填产品名称；未逐一选择全部漏洞子类型、52 个业务，仍可能存在额外联动。

标题按页面“漏洞类型 + 受影响资产 + 风险能力”格式概括，只写证据支持的能力，不能复制示例中的“批量获取手机号”。`details` 保留以下六节：

1. **漏洞摘要（必填）**：漏洞机制及触发条件。
2. **受影响资产（必填）**：完整 URL/API 端点、应用版本、业务模块；未知项列为缺口。
3. **复现手册**：环境与工具版本、账号及权限、操作步骤、预期和实际结果均为模板必填内容，逐步关联证据。
4. **附件 POC（必填）**：请求、Payload、截图、录屏、EXP 等实际材料与步骤编号对应；使用 ZIP 时，页面要求包含说明文件对应步骤的 `README.txt`。
5. **风险影响评估（必填）**：攻击行为、影响范围和安全后果，可按机密性/完整性/可用性分析，区分事实与推测。
6. **修复建议（选填）**：针对根因提供原理性思路，避免仅给临时规避措施；依据不足可不填。

六节在同一编辑器里，不增加六个表单字段。附件 POC 小节的“必填”不自动证明独立上传按钮强制非空。材料缺失时保留具体补证项；不执行 PoC/EXP，不把附件清单当成已经打包或上传。

## 附件和人工事项

上传文案支持 doc、docx、7z、zip、gz、bz2、excel，DOM `accept` 将 excel 明确为 `.xlsx`、`.xls`；未观察到 PDF 支持。文件**小于 20M**，配置 20000000 字节只作保守十进制预检，单位和服务端接受边界未验证。

控件没有 `multiple`，只说明单次选一个文件，总附件数未知。标题未见 DOM maxlength，正文长度与编辑器图片规则未确认；不能解释为后台无限制。真实账号或凭证保持受控定位，分享内容一致脱敏。协议由用户人工处理，协议全文尚未核验。
