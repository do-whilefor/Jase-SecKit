核对日期：2026-10-03（Asia/Shanghai）。通过 Chrome MCP 读取用户当前打开的三个漏洞提交页面，核对表单、页面说明、DOM 属性及下拉选项。

## 阅读说明

- **页面必填**：依据页面星号、必填样式或语义标记确认，未通过实际提交验证服务端校验。
- **未标记**：页面没有明确的必填标记，不等于已确认可以留空。
- **条件字段**：在特定选择或可选模块展开后出现；所属条件写在对应章节。
- **未显示限制**：仅表示页面提示及已检查的 DOM 没有给出限制，不代表后台无限制。
- 本次未提交漏洞、保存草稿、上传文件或执行漏洞验证。读取到的选项是采集时状态，后续可能变化。
- 三站章节各自完整保留原始字段名称，不以通用字段表替代各站要求。
